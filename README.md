\# Bondora – Peer-to-Peer Lending Risk \& Profitability Analysis



\## 📌 Project Overview



This project analyzes peer-to-peer lending data from Bondora to understand loan performance, borrower characteristics, credit risk, default behavior, outstanding portfolio exposure, and profitability.



The project follows an end-to-end data analytics workflow using Python, SQL Server, and Power BI.



\## 🎯 Business Objectives



\- Analyze borrower and loan characteristics

\- Identify factors associated with loan defaults

\- Evaluate portfolio risk across different risk categories and credit ratings

\- Analyze outstanding principal and repayment status

\- Measure expected return and net profitability

\- Build an interactive dashboard for business-level insights



\## 🛠️ Tools \& Technologies



\- \*\*Python\*\* – Data cleaning, transformation and exploratory analysis

\- \*\*Pandas\*\* – Data manipulation

\- \*\*SQL Server\*\* – Data storage and analytical queries

\- \*\*Power BI\*\* – Interactive dashboard and visualization

\- \*\*DAX\*\* – Measures and calculations

\- \*\*Git \& GitHub\*\* – Version control and project documentation

\## 📊 Power BI Dashboard



\### Page 1 – Borrower Profile \& Loan Distribution



Analyzes borrower demographics, loan distribution, education, employment status, age groups, and geographic distribution.



\### Page 2 – Loan Performance \& Financial Analysis



Analyzes funding, principal repayment, outstanding principal, loan duration, expected return, credit ratings, and loan performance.



\### Page 3 – Risk \& Profitability Analysis



Analyzes risk categories, default probability, default rates, portfolio exposure, and net ROI.



\## 🔍 Key Insights



\- High-risk loans show significantly higher default rates than lower-risk categories.

\- Portfolio exposure varies considerably across risk categories.

\- Credit ratings provide useful differentiation in default behavior.

\- Loan duration and expected return show important relationships in portfolio performance.

\- Outstanding principal provides an important measure of current portfolio exposure.

\- Risk and profitability should be evaluated together when assessing lending performance.
